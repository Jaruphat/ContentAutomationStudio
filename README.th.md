# Content Automation Studio — คู่มือเริ่มต้น

**[English README →](README.md)** · เอกสารหลักของโปรเจกต์เป็นภาษาอังกฤษ หน้านี้คือส่วนเริ่มต้นใช้งานเท่านั้น

แอปสำหรับทำหนังสั้น/คลิปเล่าเรื่องแบบรันในเครื่องตัวเอง ตั้งแต่เขียนพล็อต แตกเป็นฉากและช็อต ประกอบพรอมป์ต์ สั่ง ComfyUI สร้างภาพและวิดีโอ ตรวจงานทีละเทค แล้วตัดต่อรวมเป็นไฟล์เดียวด้วย FFmpeg

เขียนขึ้นสำหรับคนที่มีการ์ดจอและติดตั้ง ComfyUI ไว้แล้ว พัฒนาและวัดผลบน RTX 5080 (16 GB) กับ ComfyUI 0.34.0 บน Windows ตัวเลขเวลาทุกตัวในเอกสารมาจากเครื่องนั้น

**ยังไม่ต้องมีอะไรก็ลองได้** ถ้าไม่ใส่ API key และไม่เปิด ComfyUI แอปจะรันด้วย mock provider คือทุกหน้าใช้งานได้ครบ สร้างภาพเป็นภาพ placeholder และเรนเดอร์ออกมาเป็นแผนงาน เมื่อพร้อมค่อยชี้ไปที่ ComfyUI จริง

## สิ่งที่ต้องมี

| อย่าง | เวอร์ชัน | หมายเหตุ |
|---|---|---|
| Python | 3.11+ | สำหรับ backend |
| Node.js | 18+ | สำหรับ frontend |
| FFmpeg | ไม่บังคับ | ถ้าไม่มี ขั้นตอนเรนเดอร์จะบอกว่าข้ามเพราะอะไร |
| ComfyUI | ไม่บังคับ | 0.34.0 ขึ้นไป ถ้าไม่มีจะใช้ mock แทน |
| การ์ดจอ | ไม่บังคับ | 16 GB พอสำหรับทุก pipeline ในเอกสาร โดยโหลดทีละตัว |

## ติดตั้งและรัน

```bash
git clone <repo นี้> && cd ContentAutomationStudio
cp .env.example .env                 # ค่า default ใช้ได้เลย ยังไม่ต้องกรอกอะไร

cd backend
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001

# เปิด terminal อีกหน้าต่าง
cd frontend && npm install && npm run dev
```

เปิด <http://localhost:5173>

หลังติดตั้งครั้งแรกแล้ว ครั้งต่อไปดับเบิลคลิก `start-dev.bat` ได้เลย มันจะเปิดทั้ง backend และ frontend แล้วเปิดเบราว์เซอร์ให้ (ตัวมันไม่ได้ติดตั้ง dependency ให้ ถ้ายังไม่มี venv หรือ node_modules มันจะบอกว่าขาดอะไร)

## ขั้นตอนที่ข้ามไม่ได้: ลงทะเบียน workflow

ติดตั้งเสร็จใหม่ ๆ จะยังสร้างภาพไม่ได้ เพราะช็อตยังไม่รู้ว่าจะสั่งอะไร ต้องเอา workflow ของ ComfyUI เข้ามาก่อน

1. ใน ComfyUI export กราฟด้วย **Workflow → Export (API)** ไฟล์แบบ editor/UI ใช้สั่งงานไม่ได้ และแอปจะเตือนตั้งแต่ตอนนำเข้า ไม่ปล่อยให้ไปพังตอนสั่งรัน
2. เปิดหน้า **Workflows** แล้วลงทะเบียน ตั้งชื่อและเลือกประเภท (`image`, `text-to-video`, `image-to-video`)
3. ผูกชื่อฟิลด์ (`positivePrompt`, `seed`, `frames`, `referenceImage` ฯลฯ) เข้ากับ node id และชื่อ input — ที่นี่เป็นที่เดียวในทั้งระบบที่มี node id
4. ระบุ frame rate ที่กราฟเรนเดอร์ออกมา เพราะความยาวคลิปสั่งเป็นจำนวนเฟรม ถ้ากราฟเป็น 24 fps แต่โปรเจกต์คิดเป็น 30 คลิปจะยาวเกินที่สั่งไปหนึ่งในสี่
5. กด **Validate against the graph** เพื่อเช็คว่าทุกฟิลด์ที่ผูกไว้ชี้ไปยัง node ที่มีอยู่จริง และโมเดลที่กราฟเรียกใช้มีอยู่ใน ComfyUI

ถ้าไฟล์โมเดลของคุณชื่อไม่ตรงกับในกราฟ ให้แก้ชื่อในกราฟ อย่าไปเปลี่ยนชื่อไฟล์โมเดล แล้วบันทึกเหตุผลไว้ — ดูตัวอย่างได้จาก `workflows/derived/*.provenance.json`

## ลำดับการทำงานในแอป

`Story → Storyboard → Generate → Review → Timeline → Export`

เขียนบทและสร้างฉาก/ช็อต → ประกอบพรอมป์ต์ → สั่งสร้าง → ตรวจและอนุมัติทีละเทค → เรียงเป็นไทม์ไลน์จากเทคที่อนุมัติแล้วเท่านั้น → เรนเดอร์ออกเป็นไฟล์เดียว

เอกสารอื่นที่อาจมีประโยชน์:

- [คู่มือเริ่มช่องมนุษย์ก้างเล่าเรื่อง](docs/Stickman_Channel_Starter_Guide_TH.md) — แนวทางวางแผนช่องและการคุมตัวละครให้เหมือนเดิม
- [Character Episode Production Template](docs/Character_Episode_Production_Template.html) — แม่แบบการผลิตหนึ่งตอนจากตัวละครหนึ่งตัว พร้อมกฎที่ได้จากการวัดผลจริง
