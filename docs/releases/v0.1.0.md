# v0.1.0 — first public release

A local-first studio for making short narrated films: write the story, break it
into scenes and shots, compile the prompts, drive ComfyUI for the pictures and
the motion, review every take, and cut the approved ones into one file.

It runs with nothing installed. Without an API key and without ComfyUI, the
whole application works on deterministic mock providers, so you can see what it
does before downloading 30 GB of models.

## What is in it

- **Story → Storyboard → Generate → Review → Timeline → Export**, with approval
  gates before Generate and before the final render.
- **Workflow registry.** Register a ComfyUI API-format graph and bind logical
  fields (`positivePrompt`, `seed`, `frames`, `referenceImage`) to node ids.
  Node ids exist only in that mapping, never in the application's logic, so
  re-exporting a graph with different numbering is a mapping fix.
- **Character continuity.** An approved master image conditions every shot the
  character appears in, so the same character survives from shot to shot.
- **Motion.** Any approved still can be animated into a short clip that starts
  from that exact frame, and the still comes off the cut automatically.
- **Narration and subtitles**, mixed to -16 LUFS / -1.5 dBTP, with per-line
  durations measured from the recording rather than estimated.
- **Provenance on everything**: the exact graph submitted, the seed, the
  provider, the cost, and what went wrong.

## Verified on

RTX 5080 (16 GB), ComfyUI 0.34.0, Windows 11. Measured on that machine:

| Step | Workflow | Time |
|------|----------|------|
| Still | Z-Image Turbo | ~20 s |
| Reference-conditioned still | Qwen-Image-Edit 2511 Lightning, 4 steps | ~36 s |
| Motion | Wan 2.2 TI2V 5B, 10 steps | 0.74 s per frame |
| Motion | MiniMax H3 turbo, 8 steps | 1.78 s per frame |

## Known limitations

- Developed and run on Windows. Nothing in it is Windows-only by design, but
  the other platforms are untested.
- The models are not included and are not small. The README says which ones
  each pipeline needs, how large they are, and which folder they go in.
- A fresh install cannot generate anything until a workflow is registered and
  mapped. That is the one step with no default.
